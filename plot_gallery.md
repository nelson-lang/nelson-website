# Plot gallery

Every image below was produced with Nelson's built-in graphics, a few lines of code in
each case, rendered by the rebuilt backend-agnostic engine that draws identically on the
native desktop, headless, in the [web desktop](web-desktop.md), and in WebAssembly.
